# שיעורי הבית שלי

צ'קליסט משימות לשיעורי בית - דף אחד, בעברית, מותאם לטלפון.

**באוויר:** https://hadasgit.github.io/homework-checklist/

## מה יש בו

8 מקצועות, 33 משימות: מדעים, מתמטיקה, גיאומטריה, אנגלית, שפה, תרבות ישראל, תקנון, ספרות.
סרגל התקדמות באחוזים למעלה, והודעת סיום כשהכול מסומן.

הסימונים נשמרים אוטומטית בדפדפן (localStorage) - אפשר לסגור ולחזור, והכול נשאר.
השמירה היא לכל מכשיר ודפדפן בנפרד: מה שמסומן בטלפון לא מופיע במחשב.

יש כפתור איפוס בתחתית הדף, עם שאלת אישור לפני.

## עריכת רשימת המשימות

המשימות מוגדרות ב-`index.html`, במשתנה `groups` בתוך תגית ה-script.
כל שורה היא מקצוע אחד ורשימת המשימות שלו. לשנות שם, להוסיף או להוריד משימה -
עורכים שם ישירות ודוחפים לגיט, והדף מתעדכן תוך כדקה.

שימו לב: הסימונים נשמרים לפי מספר סידורי של המשימה, אז הוספה או הסרה של משימה
באמצע הרשימה מזיזה את הסימונים הקיימים. הכי נוח לעדכן כשהרשימה ריקה או אחרי איפוס.
